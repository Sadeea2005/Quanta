# Quanta

A minimal to-do list app built with HTML, CSS and vanilla JavaScript.

## Features
- Add tasks with the Add button or the Enter key
- Double-click a task to edit it
- Mark tasks as completed with a checkbox
- Delete tasks you no longer need
- Tasks are saved in localStorage, so they stay after a refresh

## Tech Stack
- HTML5
- CSS3 (grid layout, responsive design)
- JavaScript (ES6)

## Run Locally
1. Clone the repository:
   git clone https://github.com/Sadeea2005/quanta.git
2. Open `index.html` in your browser, or use the Live Server extension in VS Code.
